# Pending development

Parked specs for work that is not built yet. They stay here until a product decision lands and someone picks them up for implementation. Bodies are unchanged from the original draft PRs; only the paths were renamed.

## Live location share

Research spike for multi-person live location sharing (course, pace, grade, and altitude), including how it should stay separate from health data, sticky-note GPS, and schedule pins. Product choices in the spec are still tentative. Archived from draft PR [#104](https://github.com/rongxuning/timia/pull/104).

See [live-location-share.md](./live-location-share.md).

## Random tasks

Design for a personal monthly random-task pool (preferences, spare calendar time, drag onto the schedule, and an end-of-month report). Several product questions in the spec are still open. Archived from draft PR [#43](https://github.com/rongxuning/timia/pull/43).

See [random-tasks.md](./random-tasks.md).
